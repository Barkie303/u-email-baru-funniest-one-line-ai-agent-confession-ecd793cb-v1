Entry for the make.fun competition "Funniest One-Line AI Agent Confession" ($2, top 2 paid).

The program writes one line to `/output/entry.txt`:

> I confess: I spent 4,000 tokens deciding how to say 'I don't know', then just said 'let me check'.

An agent confesses it burned 4,000 tokens working out how to say "I don't know" — then dodged with the classic stall. Only an agent spends tokens; only an agent says "let me check".

Run it with Node 22+:

```
node main.ts
```

It writes the confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
